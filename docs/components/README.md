# Componentes UI — Somos R

Sistema de componentes propio construido sobre Material UI (MUI).
Todos los componentes se importan desde `@/components/ui`.

| Componente | Descripción | Docs |
|------------|-------------|------|
| Button | Botón de acción con soporte para estado de carga | [Button.md](./Button.md) |
| Input | Campo de texto con label, error y adornments | [Input.md](./Input.md) |
| Select | Selector con opciones tipadas | [Select.md](./Select.md) |
| Dialog | Modal con título, contenido y acciones | [Dialog.md](./Dialog.md) |
| Table | Sistema de tabla con paginación | [Table.md](./Table.md) |
| Badge | Chip de estado (verificado, pendiente, etc.) | [Badge.md](./Badge.md) |
| Card | Contenedor con cabecera y contenido | [Card.md](./Card.md) |
| Alert | Mensaje de alerta con severidad | [Alert.md](./Alert.md) |
| Snackbar | Notificación temporal (toast) | [Snackbar.md](./Snackbar.md) |
